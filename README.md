# Hospital-Managment-System
Enterprise Hospital Management System built with ASP.NET Core Web API, React, React Native, SQL Server, Entity Framework Core, JWT Authentication, Clean Architecture, and modern software engineering practices.

## Overview

This is a full-stack Hospital Management System built to manage the daily operations of a hospital. The project is being developed step by step using modern technologies and software engineering practices.

The goal is to create a secure, scalable, and production-ready application while learning the complete development process from planning to deployment.

## Features

- User authentication and authorization
- Role-based access control
- Patient management
- Doctor management
- Appointment scheduling
- Medical records
- Pharmacy management
- Laboratory management
- Billing and payments
- Inventory management
- Notifications
- Reports and analytics
- Admin dashboard
- Mobile application

## Technology Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

### Frontend
- React
- React Native
- TypeScript
- Tailwind CSS

## Project Structure

The project follows Clean Architecture to keep the code organized, maintainable, and easy to scale.
